# ADR-0004: Experience York via click-to-import from the open page; fixtures + mock for development

- **Status:** Accepted (Stage 1)

## Context
No documented API; the portal is authenticated; list pages show summaries.

## Decision
Experience York via click-to-import from the open page; fixtures + mock for development.

## Alternatives considered
Headless-browser automation or login automation (rejected: access-control and policy concerns, brittleness).

## Consequences
SUMMARY/FULL completeness model; extractor versioning; demo on fixtures if needed.

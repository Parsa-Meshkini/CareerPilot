# ADR-0008: CLI as a REST API client sharing the backend with the GUI

- **Status:** Accepted (Stage 1)

## Context
Avoid duplicated business logic; the CLI works against local and deployed servers.

## Decision
CLI as a REST API client sharing the backend with the GUI.

## Alternatives considered
Django management commands calling services directly (rejected: local-only, bypasses API auth and validation).

## Consequences
Personal API tokens; `--json` output for scripting.

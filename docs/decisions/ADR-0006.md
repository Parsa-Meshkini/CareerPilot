# ADR-0006: Anti-fabrication: verified facts + citations + deterministic FabricationGuard inside a Template Method

- **Status:** Accepted (Stage 1)

## Context
Invented qualifications harm the user; prompts alone are not a guarantee.

## Decision
Anti-fabrication: verified facts + citations + deterministic FabricationGuard inside a Template Method.

## Alternatives considered
Prompt-only grounding (rejected); human review only (rejected: easy to miss).

## Consequences
Every generator inherits the guard; NEEDS_REVIEW status is surfaced in the UI and the checklist.

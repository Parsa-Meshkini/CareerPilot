# ADR-0005: Gmail via OAuth gmail.readonly in Google Testing mode; .eml and mock adapters

- **Status:** Accepted (Stage 1)

## Context
gmail.readonly is a restricted scope (verification + CASA for production); Testing-mode tokens expire in about 7 days.

## Decision
Gmail via OAuth gmail.readonly in Google Testing mode; .eml and mock adapters.

## Alternatives considered
Password/IMAP (rejected: insecure, violates least privilege); waiting for verification (rejected: timeline).

## Consequences
A reauth flow is part of the design; email detection is not blocked by Google verification.

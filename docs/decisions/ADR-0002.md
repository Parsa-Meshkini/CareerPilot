# ADR-0002: Provider-neutral LLM access through LLMClient facade + LLMProvider adapters

- **Status:** Accepted (Stage 1)

## Context
Vendor SDKs differ; cost, availability and quality vary; tests must run offline.

## Decision
Provider-neutral LLM access through LLMClient facade + LLMProvider adapters.

## Alternatives considered
Direct SDK calls in services (rejected: duplication, lock-in, untestable).

## Consequences
Gemini primary, OpenAI alternative, Mock for CI; switch via environment variables.

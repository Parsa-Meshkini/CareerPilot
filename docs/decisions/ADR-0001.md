# ADR-0001: Modular monolith (Django/DRF) with Celery workers

- **Status:** Accepted (Stage 1)

## Context
A small team, a single domain and transactional workflows (import → posting → match) favour one deployable. Scaling needs are met by stateless web replicas and per-queue Celery workers.

## Decision
Modular monolith (Django/DRF) with Celery workers.

## Alternatives considered
Microservices (rejected: operational overhead, distributed transactions, no measured need).

## Consequences
Clear Django app boundaries; an app can be extracted later only if measurements justify it.

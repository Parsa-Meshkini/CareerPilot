# ADR-0007: Human control: CareerPilot never submits applications; side-effecting agent actions need approval and are undoable

- **Status:** Accepted (Stage 1)

## Context
Accountability, ToS of employer portals, and user trust.

## Decision
Human control: CareerPilot never submits applications; side-effecting agent actions need approval and are undoable.

## Alternatives considered
Auto-submit (rejected).

## Consequences
No submit tool exists in the agent catalog; ApprovalPolicy + Command undo.

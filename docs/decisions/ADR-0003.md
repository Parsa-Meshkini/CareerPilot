# ADR-0003: No automated LinkedIn extraction; paste import only

- **Status:** Accepted (Stage 1)

## Context
LinkedIn's terms and prohibited-software policy forbid add-ons that scrape or copy data.

## Decision
No automated LinkedIn extraction; paste import only.

## Alternatives considered
Extension extraction (rejected: ToS, account risk, legal risk).

## Consequences
LinkedInBrowserImportAdapter kept disabled as an extension point for an official API.
